# 中文演示数据

- `public/config.json`：站点默认语言（简体中文）、身份、导航、分组与功能配置。
- `public/data.json`：番剧、导航、设备、友链、游戏、音乐、项目、技能和时间线。
- `public/taxonomy-aliases.json`：旧英文分类/标签查询到中文名称的兼容映射。
- `admin/albums.json`：相册源资料，含演示用保护配置，不直接公开。
- `admin/settings-labels.json`：管理设置的中文标题，配置 ID 保持不变。
- `../content/`：中文文章、动态、系列、关于页与引用片段。

运行 `pnpm content:build` 生成公开数据、管理初始数据和中文全文搜索索引。
品牌名、技术名、代码标识符、状态枚举和文件路径保持其原始含义。
`source-data/` 保存迁移时的原项目参考副本，不参与运行时或上述生成过程。

浏览器中已有的管理草稿不会被自动覆盖。需要查看新版初始数据时，先导出
自己的修改，再使用管理端的“重置数据”。已选择其他语言的浏览器仍保留
语言偏好；没有偏好的新访客默认使用简体中文。
