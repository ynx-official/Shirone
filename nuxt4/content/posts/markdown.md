# 从一段文字开始

Markdown 让你把注意力放在内容上。段落之间空一行，就能自然分开。

你可以使用 _斜体_、**粗体** 和 `行内代码` 表达不同层次的信息。

- 记录一个想法。
- 整理一段过程。
- 留下可复用的经验。

> 写作不必一次完成。
>
> 先把想法记下来，再慢慢整理成清晰的文章。

## 列表与代码

1. 明确文章要解决的问题。
2. 写出关键步骤。
3. 用示例检查读者是否能够复现。

```python
import time

for index in range(3):
    time.sleep(0.5)
    print(f"第 {index + 1} 次记录")
```

### 嵌套结构

1. 准备资料：
   - 原始记录。
   - 参考链接。
   - 需要说明的图片。
2. 完成初稿。
3. 检查措辞与格式。

可以访问 [文章归档](/archive/)，也可以跳转到 [列表与代码](#列表与代码)。这是一条脚注[^1]。

[^1]: 脚注适合放不影响主线阅读的补充信息。
