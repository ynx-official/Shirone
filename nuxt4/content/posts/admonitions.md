提示块能让补充信息更容易辨认，同时保持正文的阅读节奏。下面展示同一套 M3E 样式下的不同语义。

## 提示与警告

::: note 部署前的准备
请先确认运行环境与依赖版本，再开始构建。
:::

:::info[信息]
信息提示适合说明背景、适用范围与必要的前置知识。
:::

:::tip[试试 **简短的标题**]
标题中可以使用行内 Markdown 强调。
:::

> [!IMPORTANT]
> GitHub 风格的提示也会使用一致的视觉样式。

:::warning[警告]
构建生产版本前，请检查环境变量与功能开关。
:::

:::caution[注意]
不要把真实密码、令牌或私钥放进示例内容。
:::

## 可选详情

::: details 查看完整检查命令
使用原生折叠控件，即使未加载客户端脚本，也能通过键盘展开。

```sh
pnpm typecheck
pnpm build
```

- 默认收起较长的补充内容。
- 代码块在自身区域内横向滚动。
- 小屏幕下不撑宽文章容器。
:::

## 写法示例

```markdown
:::note[提示标题]
这里填写补充说明。
:::

> [!TIP]
> 这里填写实用建议。
```
