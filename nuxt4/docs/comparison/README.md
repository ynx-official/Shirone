## 数据口径与剩余差异

- 原站开发模式显示 22 篇，Nuxt 公开数据为 20 篇。原站的 `draft.md`、`markdown-fields.md` 是草稿，按迁移契约不加入公开 SSR、索引与 Feed。分类计数、总字数与运行天数因此可能不同；不为截图一致而暴露草稿。
- MDX 展示依然是显式 Vue 转换，不能视为原 MDX 所有示例均已迁完。
- 本次核对了以上 5 页，尚未完成其余专用页面、全部配置组合、搜索弹层、灯箱、全部 FAB 动作和第三方 provider 的完整对齐。
- 移动首卡高度仍有约 5.5px 差异，部分次级图标、装饰、网格排列细节及页脚内容尚未做到逐像素一致。日历日期采用满足 WCAG 的文字色，不复制原站的淡灰低对比度。这里的尺寸校准不等于全站视觉验收完成。
- 相册远程封面沿用原数据，截图受原外部图片源可用性影响。没有下载远程图片作为替代。

## 复现

在项目根目录启动原站（仅对比工具会引用父 Astro 配置；Nuxt 应用不依赖它）：

```sh
pnpm exec astro dev --port 4321 --config nuxt4/scripts/astro-reference.config.mjs
```

此配置忽略 `nuxt4/` 的文件监听，避免修改新应用时反复重启原站。

另一个终端进入 `nuxt4/`：

```sh
pnpm dev --host 127.0.0.1
node scripts/compare-original.mjs after
```

`before` 参数用于首次采集原站及旧 Nuxt；现有 `before/` 是此次修复前证据，通常不要覆盖。浏览器回归位于 `tests/browser/visual-parity.spec.ts`，验证几何尺寸、移动封面／导航、归档／集合筛选、显示设置持久化与播放器跨路由保留。

构建产物的截图可用 `NUXT_COMPARE_PORT=4323 node scripts/compare-original.mjs after` 采集。最新公开生产浏览器测试 7/7 通过，具体证据见 ../validation.md。
