# Shirone → Nuxt 4 独立应用实施计划

## 1. 目标与边界

新应用全部位于 `nuxt4/`。目标栈为 Nuxt 4.5、Vue 3、TypeScript、Vite 8、Tailwind 4、必要的 Stylus、Nitro Node SSR。使用兼容的官方版本组合，独立 package.json 和 pnpm-lock.yaml，不使用依赖 overrides 强行拼装。

保留原 Astro 项目作为只读内容、功能和视觉基线；不删除旧栈，不修改根目录脚本、工作流，不创建嵌套 Git，不部署或切换线上服务。新应用不再维护 npm 主题安装、集成与配置覆盖机制。

第一阶段不连接真实后端、数据库或对象存储。提供真实公开 SSR 和浏览器本地的全站管理演示；未来 API 只替换数据适配器。

## 2. 目录与职责

| 路径 | 职责 |
| --- | --- |
| app/pages、layouts | 公开路由、管理路由、持久外壳 |
| app/components/atoms、molecules、organisms | 按层级迁移实际被页面使用的组件 |
| app/components/content、admin | Markdown 增强与通用管理表单 |
| app/composables、repositories | 请求级状态、异步数据访问、浏览器适配器 |
| app/i18n、assets、utils | 十语言字典、M3E 令牌、生命周期工具 |
| shared/types、schemas | DTO、版本化导入契约、统一实体模型 |
| server/api/mock、services、utils | 内部只读 API、内容读取、Feed 等输出 |
| mock/public、mock/admin | 配置/公开数据快照与私有构建数据 |
| content、public | 正文与本地资源 |
| scripts | 编译、索引、缩略图、验证；所有可执行验证脚本留在本目录 |
| tests、docs | 自动测试、迁移清单、来源、差异与运行说明 |

需要复用的原代码和资源复制到新目录并记录来源，运行时不得向父项目解析源码或依赖。

## 3. 数据与交互契约

数据契约 → Repository → Adapter。页面用 useAsyncData/useFetch 获取 SSR 数据并复用 payload。列表 DTO 不包含正文和加密包，详情 DTO 按需返回内容。Node 文件访问、内容全集和管理初始数据不进入公开客户端模块。

公开内容在构建时编译 Markdown、TOC、语法特征、URL 索引和 Pagefind 索引。Nitro 从打包的 server assets 读取，不在每次请求中重编译正文。项目内容修改后重新构建部署。

管理端使用 `shirone:admin:v1` 保存版本化 JSON 覆盖项，图片原文件用 IndexedDB。保存成功必须在浏览器存储写入成功之后显示。导入先校验版本、结构、重复 ID 和秘密字段；无效数据不得覆盖已有数据。分类、标签、系列重命名同步关联；删除被引用项目阻止并提示影响。

本地编辑只影响管理和专用预览。公开 SSR 不读取浏览器覆盖项。“已发布”只表示演示数据状态，不表示上线。生产构建默认移除管理路由并关闭管理、include 数据接口；不提供伪登录。

图片 Blob URL 离开页面或不再使用时释放。浏览器预览动态加载同源 Markdown 编译器；include 只能访问服务器登记的 snippets，不允许任意文件路径。秘密凭据不能保存在浏览器配置。

## 4. 功能顺序与迁移要求

1. 先完成令牌、字体、SSR 图标、主题、响应式和基础 shell。
2. 实现首页 → 普通正文 → 特殊语法正文的垂直链路，验证直达、切页、返回及 hydration。
3. 完成归档、分类、标签、系列与保留永久链接/别名的 URL 索引。系统和管理路由必须被保留，冲突时构建失败。
4. 迁移动态、相册、友链、番剧、项目、技能、设备、游戏、时间线、导航、关于页的真实数据字段和交互。
5. 按内容特征加载 Mermaid、代码树、音视频、GitHub 卡片等增强；在 Vue 生命周期中清理观察器、事件、播放器和异步任务。
6. Nuxt layout 承载主题、侧栏和持续音乐状态，Vue Router 替换 Swup。服务端不能通过模块级可变状态共享用户信息。
7. 加入 Pagefind、TOC、分享、RSS、Atom、sitemap、robots、llms 和错误页。
8. 旧 Svelte MDX 示例转换为 Vue 展示组件，保留 URL；每个其他 MDX 必须显式迁移，不能默默执行或丢弃任意旧代码。

可选能力关闭时不得生成占位 DOM、加载 SDK 或请求第三方。mock 默认关闭真实评论、统计和远程数据。启用行为通过 fixtures 验证。图片使用构建缩略图与原生输出，不引入运行时图片代理。

受保护正文不得出现在 HTML、payload、Feed、搜索、llms 或公开列表中。加密相册保留布局；已知公开图片路径仍可直接访问，不能宣称是服务端授权。

## 5. 管理模块

| 模块 | 操作 |
| --- | --- |
| 概览 | 数量、最近编辑、本地修改状态 |
| 文章 | 搜索/筛选、新建、编辑、草稿状态、删除、Markdown 预览 |
| 分类/标签/系列 | 增删改、排序、关联检查 |
| 动态 | 正文、日期、标签和图片 |
| 相册/媒体 | 元数据、照片列表/排序、IndexedDB 上传与删除 |
| 友链/导航 | 分组、URL、图标与顺序 |
| 番剧/项目/技能/设备/游戏/时间线/音乐 | 各数据模型的增删改查 |
| 站点/功能设置 | 身份、导航、侧栏、主题、字体、页脚、开关及第三方配置状态 |
| 数据工具 | JSON 导入/导出、重置、存储状态 |

表单与共享 schema 保持一致。管理预览与真实发布必须保持区分。媒体完整备份、配置专用语义验证、复杂组件交互如未完成，要在进度表逐项记录，不将通用字段表单等同于完整产品验收。

## 7. 必须验证的场景

- 无 JavaScript 时公开标题、正文、导航、SEO 仍可读取。
- 路由直达/跳转/返回/前进、查询参数、分页、锚点一致。
- 深浅色、移动端、键盘焦点、减少动效和无障碍；不存在 hydration 错误。
- 并发 SSR 不串状态，普通与复杂语法切换后资源清理。
- 搜索、Feed、URL 索引使用一致可见性规则，受保护内容无明文泄露。
- 管理修改刷新后仍在，重置恢复 seed，无效导入与容量不足保留旧数据。
- 预览显示本地草稿，公开 SSR 不受影响；生产管理关闭时所有相关入口均不可访问。
- 仅复制 .output 的环境可读取内容和资源；Docker 健康检查、正常停止和重启。

真实 API、数据库、对象存储、线上鉴权和发布留待下一阶段。当前证据与未完成项以 migration-progress.md 为准。
