## 已确认范围

截图仅参考结构：左侧分组导航、顶部面包屑、可关闭的路由页签、上传区与媒体卡片网格。UI 框架使用 `antdv-next`，由 `@antdv-next/nuxt` 注册组件。后台 `/admin` 及子路由采用 CSR，博客前台继续 SSR。

2026-09-20 用户修订：取消此前共享前台 M3E 配色的方案。后台采用中性灰阶，仅保留亮色、暗色切换，独立存储于 `shirone:admin:appearance`。不提供色相、配色或系统模式选项，不改写前台主题偏好。侧栏、表格、媒体卡片与 Ant 弹层使用一致的中性颜色和紧凑圆角。

文章管理默认展示完整列表，支持搜索和状态过滤；选择条目后进入独立编辑区，关闭可返回列表。

## 行为

- 16 个现有数据域及预览、导入导出保持浏览器本地编辑契约；没有新增登录、线上发布或真实后端写入。
- 页签用于路由导航，关闭当前页签后回到相邻页签；不缓存未保存表单。
- 媒体上传保留原有 JPG、PNG、GIF、WebP、AVIF 与 20 MB 限制。显示实际文件大小、图片尺寸和引用实体数；不伪造旧图片上传时间。
- “复制引用”返回 `media:<id>`，用于本地内容和预览，不是公网 URL。
- 被引用图片不可删除；单张删除及清理未引用图片均要求界面确认。批量清理使用单次 IndexedDB 事务。
- 默认生产构建继续移除管理路由与管理数据，且不启用 Ant Design Nuxt 模块。显式设置 `NUXT_MOCK_ADMIN=true` 时构建管理演示。

## 效果稿落地（2026-09-20）

用户确认生成的黑白效果稿作为优化方向。导航收窄、顶部栏和页签压缩，上传区改为横向工具条；卡片采用 16:10 图片、紧凑元信息和有可访问名称的图标操作。实际内容和功能保持原有本地数据契约，不添加效果稿中的虚构用户信息。

媒体文件名搜索不区分大小写，结果计数随筛选更新；网格/列表切换只改变展示方式，不修改数据。清理操作仍针对整个媒体库的未引用图片，与当前搜索条件无关，并继续要求确认。新增界面文案覆盖十种语言。
效果稿优化验证：11 项后台回归通过，前台主题项单独重跑通过；lint 通过，桌面与手机实页截图已检查。
本轮最终类型检查通过；手机上传条换行和横向溢出检查通过。
