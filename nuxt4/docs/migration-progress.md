## 验证记录

命令从 nuxt4 执行；实际测试结果见 docs/validation.md。

- `pnpm typecheck`：Nuxt/Vue 类型检查。
- `pnpm lint`：Vue/TypeScript ESLint；不修改文件。
- `pnpm test`：8 项契约测试，涵盖数据可见性、URL 唯一性、导入、持久化、quota、引用和公开元数据清理。
- `pnpm test:e2e`：现有 17 项 Chromium 测试（含新增 4 项视觉/交互回归），含批量公开路由与并发请求、禁用 JS、搜索、加密、本地编辑/预览/重置、IndexedDB、手机布局、第三方隔离和首页 axe。
- `pnpm dlx node@24.11.1 scripts/verify-node24.mjs`：Node 24 内容生成、构建、复制产物运行。
- `docker build -t shirone-nuxt:local .`、`node scripts/verify-docker.mjs`：隔离镜像内 SSR/资源/健康检查/非 root/停止重启。
