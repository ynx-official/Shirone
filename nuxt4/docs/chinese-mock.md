# 中文默认站点与演示内容

默认语言为简体中文（配置值 `zh_CN`，HTML 使用 `zh-CN`）。已有的语言
Cookie 仍代表访客主动选择，不会被站点默认值覆盖。可从顶部语言入口切回中文。

本轮更新覆盖站点身份与横幅、公告、导航、分类分组、20 篇公开文章与 2 篇
草稿、6 条动态、2 个系列、关于页、公共引用片段，以及番剧、导航、设备、
友链、游戏、音乐资料、项目、技能、时间线、相册和管理设置标题。

正文使用中文演示内容，保留代码标识符、技术/品牌名称与原媒体文件。
图表类型、代码块选项和图片网格布局继续提供对应展示。管理页面仍使用
浏览器本地覆盖项，已有编辑不会被自动覆盖；如需载入新版初始数据，先导出
已有修改，再执行“重置数据”。

兼容性：

- 文章与系列 ID、文章 URL、相册目录、资源路径、枚举状态保持稳定。
- `taxonomy-aliases.json` 将旧英文分类/标签查询映射到中文名称。
- 内容修改后运行 `pnpm content:build`，同步更新公开数据、管理初始数据与
  Pagefind 中文索引；Feed 和 llms 输出继续读取同一份公开数据。
- 加密正文不进入公开 HTML、API、搜索索引或订阅源；演示口令与加密边界不变。

验证见 `validation.md`。旧项目及 `mock/source-data` 中的迁移参考资料不参与
新站点的数据生成，保持原始参考内容。
